# 신들의 신탁 — 그리스 신화 인생 사주 서비스 디자인 브리프

## 한 줄 컨셉
생년월일시를 입력하면 실제 명리학(사주팔자) 계산과 서양 점성술(네이털 차트) 계산을 근거로, 그리스 신들이 각자의 영역에서 1인칭으로 "인생 신탁"을 내려주는 서비스. "오디세이" 신드롬 타이밍에 맞춘 그리스 로마 신화 IP + 한국식 사주 콘텐츠의 결합.

핵심 차별점: 다른 "재미로 보는" 신화 운세 서비스들과 달리, **실제 사주팔자·천체 계산 엔진**을 백엔드에 두고 그 결과를 그리스 신 캐릭터가 "해석"해주는 구조. 목업이 아니라 진짜 계산 위에 캐릭터를 얹은 것.

---

## 핵심 플로우

1. **입력**: 이름(선택) · 생년월일 · 출생 시·분(선택) · 성별(선택) · 정밀 모드 토글(진태양시 보정)
2. **로딩**: 불꽃 아이콘이 깜빡이며 "올림포스에 전갈이 도착했습니다…" 같은 신탁풍 문구가 순환
3. **결과** (아래 순서로 스크롤):
   - 수호신 배지 (생일 별자리 기반 배정) + 인사말
   - 궁합의 신 카드 (수호신과 신화적으로 가장 잘 맞는 신 + 궁합 신탁)
   - 사주 원국 카드 (년주·월주·일주·시주 간지 + 십신 라벨 + 오행 분포)
   - 천체 배치 카드 (태양·달·수성~토성이 태어난 순간 어느 별자리에 있었는지)
   - 다섯 신의 신탁 카드 5개 (총운/애정운/관계운/재물운/경고 — 각각 다른 신이 1인칭으로)
   - 복사하기 / 다시 묻기 버튼

---

## 계산 엔진 (이미 구현됨 — 이 로직 결과를 디자인에 활용)

- **사주팔자**: 60갑자 순환(일주), 절기 기준 년주·월주 판정(입춘·경칩 등), 오호둔/오서둔 공식으로 월간·시간 계산
- **오행**: 년/월/일/시주의 천간·지지를 목화토금수로 집계
- **십신**: 일간 기준 나머지 7글자와의 생극·음양 관계로 비견/겁재/식신/상관/편재/정재/편관/정관/편인/정인 판정
- **진태양시 보정**: 표준시-실제 경도 차이 + 균시차를 반영하는 정밀 모드 (토글로 on/off)
- **네이털 차트**: 케플러 방정식 기반 저정밀 궤도 공식으로 태양·달·수성·금성·화성·목성·토성의 황경 계산 → 12궁 별자리 환산

이 모든 계산 결과가 신탁 문구의 근거 데이터로 AI 프롬프트에 들어가서, "지어낸 운세"가 아니라 "계산된 데이터를 신이 해석하는" 구조를 만듭니다. 디자인에서도 이 "진짜 계산"이라는 신뢰감이 드러났으면 합니다 (예: 원국 카드가 단순 장식이 아니라 실제 데이터 리포트처럼 보이게).

## 12신 로스터 (수호신 배정용 — 서양 점성술 12궁 날짜 경계 + 전통 행성 지배신 매칭)

| 별자리 | 신 | 상징 |
|---|---|---|
| 양자리 | 아레스 | 검 |
| 황소자리 | 아프로디테 | 조개 |
| 쌍둥이자리 | 헤르메스 | 카두케우스 지팡이 |
| 게자리 | 아르테미스 | 초승달+화살 |
| 사자자리 | 아폴론 | 태양 |
| 처녀자리 | 데메테르 | 밀 이삭 |
| 천칭자리 | 헤라 | 왕관/공작 |
| 전갈자리 | 헤파이스토스 | 망치 |
| 사수자리 | 제우스 | 번개 |
| 염소자리 | 포세이돈 | 삼지창 |
| 물병자리 | 아테나 | 부엉이 |
| 물고기자리 | 디오니소스 | 포도송이 |

+ 크로노스(모래시계) — 네이털 차트의 토성 자리에만 등장

## 다섯 신탁 항목 (고정 배정)
- 총운 → 제우스 (위압적)
- 애정운 → 아프로디테 (관능적, 다정)
- 인연·관계의 팔자 → 헤라 (엄격, 준엄)
- 재물·성공운 → 헤르메스 (재치있고 경쾌)
- 신의 경고 → 아레스 (거칠고 도발적)

## 궁합 매칭 (6쌍, 신화 관계 기반)
제우스↔헤라(부부) · 아프로디테↔아레스(연인) · 포세이돈↔데메테르(바다+대지) · 아폴론↔아테나(이성+통찰) · 아르테미스↔헤르메스(자유로운 영혼) · 헤파이스토스↔디오니소스(정반대의 보완)

## 지금까지 확정된 비주얼 방향 (참고용 — 그대로 가도 되고 재해석해도 됨)

- **팔레트**: 짙은 남색-검정 신전 밤하늘 배경(#0B0E1A~#171B2E) + 금박 골드 액센트(#C9A227) + 신마다 고유 색(제우스=골드, 아프로디테=로즈, 헤라=퍼플, 아레스=크림슨, 포세이돈=딥블루 등)
- **타이포**: 영문/장식용 — Cinzel(로마 비문체 세리프), 한글 본문/제목 — Noto Serif KR, UI 유틸리티 텍스트 — Noto Sans KR
- **시그니처 요소**: 신전 기둥+박공지붕 실루엣(SVG 라인아트, 사진 대신), 불꽃 깜빡임 로딩 애니메이션, 별자리 점묘 배경, 신마다 다른 라인아트 심볼 아이콘(초상화 대신 신물로 캐릭터 표현 — 저작권/톤 양쪽에 안전)
- **레이아웃**: 단일 컬럼, 중앙 정렬, 신탁 카드들은 신전 비석(stele)처럼 개별 카드로 순차 등장 (스태거 애니메이션)

---

## 톤 & 카피 가이드
- 신탁체 어미 사용: ~하리라, ~할지니, ~노라, ~도다, ~이니라 (예스럽고 근엄한 문어체)
- 신마다 뚜렷한 캐릭터 구분이 핵심 — 같은 신탁체 안에서도 제우스는 위압적, 아프로디테는 관능적, 헤라는 준엄, 헤르메스는 경쾌, 아레스는 거침
- "오늘의 운세"가 아니라 "타고난 팔자/인생 전체"를 다루는 톤 — 일일운세식 표현 지양

---

## 비즈니스 방향 (참고)
- 유료화 논의 중: 총운은 무료 공개, 나머지 4개 신탁(애정/관계/재물/경고)을 프리미엄으로 잠그는 페이월 구조 검토 중 (현재 데모 버전은 전부 무료 공개 상태)
- 실제 결제 연동은 별도 백엔드(토스페이먼츠 등) 필요 — 디자인 단계에서는 잠금 UI 패턴만 고려하면 됨
